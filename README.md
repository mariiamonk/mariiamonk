## `~/projects`

### `01` — computer vision × sign language

A mobile application concept for **Russian Sign Language recognition**.

The idea is to make communication between a Deaf / hard-of-hearing person and a hearing person more accessible:

```text
camera
   │
   ▼
gesture recognition
   │
   ▼
Russian Sign Language
   │
   ▼
text / speech
```

The application is planned around real-time computer vision and an interface designed specifically for communication rather than simply recognising isolated gestures.
